## 一、目标与范围

**目标**：将 phase 1 搭建的 6 个基础组件/页面（Sidebar、NowPlayingBar、HomeView、LibraryView、SettingsView、PlayerView）从"占位骨架"细化为"视觉与交互上接近 BBPlayer"的 MD3 风格成品。

**范围**：
- 补全 `src/style.css` 中缺失的 MD3 令牌（elevation 阴影、字体、scrim、color-scheme 等）
- 引入图标系统替换全站 emoji
- 引入 Lottie 动画复刻播放控制按钮
- 增强播放器 store（模拟播放进度、seek、播放模式）
- 抽取通用 MD3 组件（IconButton / 封面占位符 / Slider / Switch）
- 细化每个组件/页面的布局、配色、尺寸、交互
- 补全 404 路由与路由过渡动画

**不在 phase 2 范围**（留待后续阶段）：
- 真实音频播放（Howler / HTMLAudio）
- B 站 API 接入与真实数据
- 歌词面板、播放队列抽屉（结构复杂，单独阶段）
- 皮肤系统、封面取色（Skia/Canvas 方案，桌面端成本高）
- ESLint / Prettier / 测试框架

## 二、当前状态分析（phase 1 遗留问题）

通过对照 BBPlayer 源码，当前项目存在以下与 MD3 视觉差距：

### 设计令牌层面
1. `--md-elevation-level*` 是纯色块而非真实 `box-shadow`，导致卡片/浮动栏缺少层次感
2. 缺 `color-scheme: light dark` 声明，原生控件（range/scrollbar）不跟随主题
3. 未使用 Tailwind v4 `@theme` 块，所有 MD3 class 都得手写 `bg-[var(--md-xxx)]`，冗长易错
4. 缺字体 `font-family`（Roboto / Noto Sans SC）
5. 缺 `--md-scrim`（半透明遮罩）、`--md-primary-fixed` 等 M3 补充令牌
6. scrollbar / range input 无 MD3 自定义样式

### 图标与视觉
7. 全站用 emoji（🏠 📚 ⚙️ 🎵 ⏮ ⏸ ▶️ ⏭ 🔀 🔁）占位，与 MD3 视觉不搭
8. 封面用 `from-purple-400 via-pink-400 to-orange-300` 渐变 + 🎵，**完全脱离 MD3 调色板**，应改为基于 `--md-primary`/`--md-tertiary` 的渐变
9. Sidebar 无 logo，标题只是纯文字

### 交互与功能
10. `currentTime` 不自增（store 无定时器），进度条永远停在 0 — **最影响体验**
11. 进度条不能拖动 seek（无 `@input` + `seek` action）
12. shuffle/repeat/queue 按钮纯占位，无状态
13. 搜索框无 `v-model`、无放大镜图标
14. 设置页全是静态文本，无真实 Switch 控件
15. LibraryView tab 无 MD3 indicator，无歌单封面
16. PlayerView 无返回按钮、无封面旋转、无模糊背景

### 路由与架构
17. 缺 `/:pathMatch(.*)*` 404 兜底（AGENTS.md 明确要求）
18. 无路由切换 Transition

## 三、技术决策（选型与理由）

### 决策 1：图标库 — `@iconify/vue` + `material-symbols:rounded`

**为什么**：BBPlayer 用 `@react-native-vector-icons/material-design-icons`（MDI 命名，kebab-case 如 `bookshelf`、`skip-next`）。Iconify 的 `material-symbols` 图标集命名几乎一致，且支持按需加载（不会打包整个图标库）。`rounded` 变体最接近 MD3 默认风格。

**替代方案对比**：
- `@fontsource/material-symbols-rounded`：字体方案，全量加载，但简单
- `lucide-vue-next`：线条风格，命名不同，偏离 MD3

### 决策 2：动画 — `vue3-lottie` 复用 BBPlayer 的 Lottie JSON

**为什么**：BBPlayer 的播放/暂停/上一首/下一首按钮用 Lottie 矢量动画（位于 `BBPlayer/apps/mobile/src/assets/lottie/`），是视觉精华。`vue3-lottie` 可以直接复用这些 JSON 文件，1:1 还原。其余过渡用 Vue `<Transition>` + CSS。

### 决策 3：播放进度 — 模拟播放（`@vueuse/core` 的 `useIntervalFn`）

**为什么**：phase 1 计划明确"音频播放"属未来阶段。phase 2 用定时器模拟进度自增（每秒 +1s），让进度条"活"起来，验证视觉交互。`@vueuse/core` 顺手解决 `useIntervalFn`、`useMediaQuery`（主题感知）等工具。

### 决策 4：主题切换 — 跟随系统 + 简单手动切换 store

**为什么**：BBPlayer 跟随系统，但设置页有"主题"项。phase 2 做一个 `theme.ts` store，支持 `light/dark/system` 三态，通过给 `<html>` 加 `class="dark"` 或 `style.color-scheme` 覆盖。比纯媒体查询灵活，且让设置页的"暗色模式"项变成真实控件。

**实现方式**：保留 `@media (prefers-color-scheme: dark)` 作为系统默认，额外用 `[data-theme="dark"]` 属性选择器支持手动覆盖。

### 决策 5：字体 — `@fontsource-variable/roboto-flex` + `@fontsource/noto-sans-sc`

**为什么**：MD3 官方推荐 Roboto。中文用 Noto Sans SC。Variable 字体一个文件覆盖所有字重，体积小。

## 六、实施步骤

### 步骤 1：补全 MD3 设计令牌（`src/style.css`）

**做什么**：在现有 `style.css` 基础上补全 BBPlayer 用到但当前缺失的令牌，并启用 Tailwind v4 `@theme` 映射。

**为什么（学习点）**：
- MD3 的"elevation"不只是颜色变浅，还包括 `box-shadow`。BBPlayer 的浮动 NowPlayingBar 阴影值是 `0 3px 4.65px rgba(0,0,0,0.29)`，这是视觉层次的关键
- `color-scheme` CSS 属性让浏览器原生控件（scrollbar、input range、表单）自动跟随主题，无需手动样式
- Tailwind v4 的 `@theme` 块把 CSS 变量映射成工具类（`--color-md-primary` → `bg-md-primary`），告别冗长的 `bg-[var(--md-primary)]`

**具体改动**：

1. 在 `:root` 和 `@media (prefers-color-scheme: dark)` 中补：
   - `--md-elevation-shadow-level0` ~ `--md-elevation-shadow-level5`（box-shadow 值，参考 MD3 规范：level1=`0 1px 2px rgba(0,0,0,0.3), 0 1px 3px 1px rgba(0,0,0,0.15)`）
   - `--md-scrim: rgba(0,0,0,0.32)`
   - `--md-primary-fixed` / `--md-primary-fixed-dim` / `--md-on-primary-fixed`（M3 新版色调）
   - `--md-surface-container-lowest` / `--md-surface-container-low` / `--md-surface-container` / `--md-surface-container-high` / `--md-surface-container-highest`（5 级表面色，BBPlayer 大量使用）

2. 加 `color-scheme: light dark` 到 `:root`，暗色媒体查询里改 `color-scheme: dark`

3. 加 `[data-theme="dark"]` 属性选择器，内容复用暗色令牌（支持手动切换）

4. 加 `@theme` 块映射常用令牌：
   ```css
   @theme {
     --color-md-primary: var(--md-primary);
     --color-md-on-primary: var(--md-on-primary);
     --color-md-primary-container: var(--md-primary-container);
     --color-md-on-primary-container: var(--md-on-primary-container);
     --color-md-secondary: var(--md-secondary);
     /* ... secondary/tertiary/surface/error 全套 ... */
     --color-md-surface: var(--md-surface);
     --color-md-surface-variant: var(--md-surface-variant);
     --color-md-surface-container: var(--md-surface-container);
     --color-md-surface-container-high: var(--md-surface-container-high);
     --color-md-on-surface: var(--md-on-surface);
     --color-md-on-surface-variant: var(--md-on-surface-variant);
     --color-md-outline: var(--md-outline);
     --color-md-outline-variant: var(--md-outline-variant);
     --color-md-error: var(--md-error);
     --radius-md-sm: 4px;
     --radius-md-md: 8px;
     --radius-md-lg: 16px;
     --radius-md-xl: 24px;
   }
   ```

5. 加全局 `body { font-family: 'Roboto Flex Variable', 'Noto Sans SC', sans-serif; }`

6. 加 MD3 scrollbar 样式（`::-webkit-scrollbar` 细条 + hover 变粗）

7. 加 MD3 range input 基础样式（`::-webkit-slider-thumb` 圆形 primary 色）

**需要修改的文件**：`src/style.css`

**如何验证**：在组件中把 `bg-[var(--md-surface)]` 改写成 `bg-md-surface`，确认两者渲染一致；浏览器开发者工具查看 `box-shadow` 是否生效；切换系统主题看原生控件是否跟随。

### 步骤 4：主题 store（`src/stores/theme.ts`）

**做什么**：创建主题切换 store，支持 `light` / `dark` / `system` 三态，持久化到 localStorage，应用到 `<html>` 的 `data-theme` 属性。

**为什么（学习点）**：
- Pinia setup store 写法 + `@vueuse/core` 的 `useStorage` 实现持久化
- `useMediaQuery('(prefers-color-scheme: dark)')` 响应系统主题变化
- 通过 `watchEffect` 把主题应用到 `document.documentElement`，让 CSS `[data-theme="dark"]` 选择器生效

**具体改动**：

```ts
import { computed, watchEffect } from 'vue'
import { useStorage, useMediaQuery } from '@vueuse/core'

export type ThemeMode = 'light' | 'dark' | 'system'

export const useThemeStore = defineStore('theme', () => {
  const mode = useStorage<ThemeMode>('bbp-theme', 'system')
  const systemDark = useMediaQuery('(prefers-color-scheme: dark)')
  const isDark = computed(() => mode.value === 'dark' || (mode.value === 'system' && systemDark.value))

  watchEffect(() => {
    document.documentElement.setAttribute('data-theme', isDark.value ? 'dark' : 'light')
  })

  function setMode(m: ThemeMode) { mode.value = m }

  return { mode, isDark, setMode }
})
```

**需要修改的文件**：新建 `src/stores/theme.ts`；`style.css` 加 `[data-theme="dark"]` 选择器

**如何验证**：在设置页切换主题，全站颜色立即变化；刷新页面后主题保持。

### 步骤 5：播放器 store 增强（`src/stores/player.ts`）

**做什么**：在现有 store 基础上补全：模拟播放进度定时器、`seek` action、播放模式（shuffle/repeat）、`volume`。

**为什么（学习点）**：
- `useIntervalFn` 来自 `@vueuse/core`，比 `setInterval` 更安全（自动在 unmount 时清理，响应 `isPlaying` 暂停）
- 播放模式用字面量联合类型 + `computed` 派生按钮状态，比布尔值更清晰
- `seek(time)` 是 PlayerView 进度条拖动的关键 action

**具体改动**：

1. 新增 state：`volume: ref(80)`、`shuffle: ref(false)`、`repeat: ref<'off' | 'all' | 'one'>('off')`
2. 新增 action：
   - `seek(time: number)`：设置 `currentTime.value = time`
   - `toggleShuffle()`、`cycleRepeat()`：循环切换模式
3. 新增 composable `src/composables/usePlaybackProgress.ts`：
   ```ts
   import { useIntervalFn } from '@vueuse/core'
   export function usePlaybackProgress() {
     const store = usePlayerStore()
     const { pause, resume } = useIntervalFn(() => {
       if (store.currentTime < store.currentTrack.duration) {
         store.currentTime++
       } else {
         store.next()
       }
     }, 1000, { immediate: false })
     watch(() => store.isPlaying, (playing) => playing ? resume() : pause(), { immediate: true })
   }
   ```
   在 `App.vue` 或 `PlayerView` 中调用一次即可驱动全局进度。
4. 假数据补 `coverUrl`：用 picsum 或留空由 `CoverPlaceholder` 兜底（推荐留空，演示占位符组件）

**需要修改的文件**：`src/stores/player.ts`；新建 `src/composables/usePlaybackProgress.ts`

**如何验证**：点播放后进度条每秒前进；拖动进度条能跳转；切换 shuffle/repeat 按钮状态变化。

### 步骤 6：通用 MD3 组件（`src/components/common/`）

**做什么**：抽取 4 个复用组件，作为细化各页面的基础积木。

**为什么（学习点）**：
- BBPlayer 在 `src/components/common/` 自研了 `IconButton`、`Button`、`CoverWithPlaceHolder` 等通用组件，是 MD3 视觉一致性的基础
- Vue 3 `<script setup>` + `defineProps` + slot 组合，比 React 的 props + children 更简洁
- 封面占位符用标题字符串 hash 生成渐变色，保证无图时也有视觉区分度（BBPlayer 的 `CoverWithPlaceHolder.tsx` 实现）

#### 6.1 `IconButton.vue`

MD3 图标按钮：默认 40×40 圆形，hover 态 `state-layer`（primary 8% 透明叠加），点击 ripple。参考 BBPlayer `IconButton.tsx`。

**Props**：`icon: string`（Iconify 名）、`size?: number = 24`、`color?: string`（默认 `on-surface-variant`）、`disabled?: boolean`

**关键样式**：
```vue
<template>
  <button :disabled class="md3-icon-btn" :style="{ color }">
    <Icon :icon :width="size" :height="size" />
  </button>
</template>
<style scoped>
.md3-icon-btn {
  @apply w-10 h-10 rounded-full flex items-center justify-center transition-colors;
}
.md3-icon-btn:not(:disabled):hover { @apply bg-[var(--md-on-surface)]/[0.08]; }
.md3-icon-btn:not(:disabled):active { @apply bg-[var(--md-on-surface)]/[0.12]; }
.md3-icon-btn:disabled { @apply opacity-38 cursor-not-allowed; }
</style>
```

#### 6.2 `CoverPlaceholder.vue`

基于标题 hash 的渐变封面占位符。参考 BBPlayer `CoverWithPlaceHolder.tsx`。

**Props**：`title: string`、`size: number`、`rounded?: boolean = true`

**实现**：用标题字符串算 hash → 映射到 `--md-primary`/`--md-tertiary`/`--md-secondary` 三色之一做渐变，中间显示首字母（`fontSize = size * 0.45`，半透明白）。

#### 6.3 `MD3Slider.vue`

自定义进度条。BBPlayer 用原生波浪滑块，桌面端用 `<input type="range">` + CSS 自定义。

**Props**：`modelValue: number`、`max: number`、`disabled?: boolean`

**关键 CSS**：active track 用 primary，inactive 用 surface-variant，thumb 是 16px 圆形 primary。用 `background: linear-gradient(...)` 根据 value 动态计算填充比例。

#### 6.4 `MD3Switch.vue`

MD3 开关。参考 BBPlayer `UniversalSwitch.tsx`。

**Props**：`modelValue: boolean`

**关键样式**：关态 36×16 椭圆 outline 边；开态 52×32 椭圆 primary 填充 + 右侧 24px 圆形 on-primary thumb。用 `<Transition>` 让 thumb 滑动。

**需要修改的文件**：新建 `src/components/common/IconButton.vue`、`CoverPlaceholder.vue`、`MD3Slider.vue`、`MD3Switch.vue`

### 步骤 13：路由补全与过渡动画

**做什么**：加 404 兜底路由，App.vue 用 `<Transition>` 包裹 `<RouterView>` 实现路由切换淡入淡出。

**为什么（学习点）**：
- AGENTS.md 路由约定明确要求 `/:pathMatch(.*)*` 404 路由
- Vue `<Transition>` 的 `name` 对应 CSS 类名前缀（`.fade-enter-active` 等），配合 `mode="out-in"` 实现先出后入
- BBPlayer 播放器页是 `slide_from_bottom`，桌面端可用 `transform: translateY()` 模拟

**具体改动**：

1. 新建 `src/views/NotFoundView.vue`：居中显示 404 + 返回首页按钮
2. `src/router/index.ts` 末尾加：
   ```ts
   { path: '/:pathMatch(.*)*', name: 'not-found', component: () => import('../views/NotFoundView.vue') }
   ```
3. `src/App.vue`：
   ```vue
   <RouterView v-slot="{ Component }">
     <Transition name="fade" mode="out-in">
       <component :is="Component" />
     </Transition>
   </RouterView>
   ```
4. `src/style.css` 加：
   ```css
   .fade-enter-active, .fade-leave-active { transition: opacity 0.2s ease; }
   .fade-enter-from, .fade-leave-to { opacity: 0; }
   ```
5. 顺带修正 `index.html` 的 `lang="en"` → `lang="zh-CN"`

**需要修改的文件**：新建 `src/views/NotFoundView.vue`；`src/router/index.ts`、`src/App.vue`、`src/style.css`、`index.html`

**如何验证**：访问 `/xxx` 不存在的路径显示 404 页；路由切换有淡入淡出。

## 七、假设与决策汇总

| 决策点 | 选择 | 理由 |
|---|---|---|
| 图标库 | `@iconify/vue` + material-symbols:rounded | 命名接近 BBPlayer 的 MDI，按需加载 |
| 动画 | `vue3-lottie` 复用 BBPlayer JSON | 1:1 还原播放按钮矢量动画 |
| 播放进度 | 模拟（`useIntervalFn`） | phase 1 明确音频属未来阶段 |
| 主题 | light/dark/system 三态 store | 让设置页"暗色模式"项变真实控件 |
| 字体 | Roboto Flex Variable + Noto Sans SC | MD3 官方推荐 + 中文支持 |
| 封面 | 留空走 `CoverPlaceholder` 占位符 | 演示占位符组件，无需真实图片资源 |
| 范围边界 | 不做歌词/队列抽屉/皮肤/音频 | 控制工作量，留待后续阶段 |
| Tailwind 映射 | 启用 `@theme` 块 | 告别 `bg-[var(--md-xxx)]` 冗长写法 |
