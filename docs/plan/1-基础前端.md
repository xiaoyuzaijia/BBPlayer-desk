## 步骤 1：创建 `router/index.ts`

**做什么**：定义 4 个路由，首页/音乐库/设置/播放器。

**涉及知识点**：
- `createRouter` + `createWebHistory` 创建路由实例
- 路由懒加载：`() => import('../views/XxxView.vue')`
- `router-link` 配合 `<RouterView />` 实现 SPA 导航
- 路由命名（`name` 属性）

**路由表设计**：

| 路径 | 名称 | 视图 | 说明 |
|---|---|---|---|
| `/` | `home` | `HomeView` | 首页 |
| `/library` | `library` | `LibraryView` | 音乐库 |
| `/settings` | `settings` | `SettingsView` | 设置 |
| `/player` | `player` | `PlayerView` | 全屏播放器 |

**需要修改的文件**：
- 新建 `src/router/index.ts`
- 修改 `src/main.ts`：`app.use(router)`

**如何验证**：手动输入 URL 路径看是否渲染对应页面。

## 步骤 2：改造 `App.vue` — 桌面布局

**做什么**：将模板自带的居中布局改为桌面**左侧 Sidebar + 右侧内容区**。

**布局结构**（CSS flexbox）：

```
┌──────────────────────────────────────────┐
│ ┌────────┐  ┌──────────────────────────┐ │
│ │        │  │                          │ │
│ │ Sidebar│  │   <RouterView />         │ │
│ │ 220px  │  │   (flex-1 主内容区)       │ │
│ │ 固定   │  │                          │ │
│ │        │  │                          │ │
│ └────────┘  └──────────────────────────┘ │
└──────────────────────────────────────────┘
```

**Tailwind class 要点**：
- 根容器：`flex h-screen bg-[var(--md-surface)] text-[var(--md-on-surface)]`
- Sidebar：`w-[220px] flex-shrink-0 border-r border-[var(--md-outline-variant)]`
- 内容区：`flex-1 flex flex-col overflow-auto relative`

**需要修改的文件**：
- `src/App.vue`

**如何验证**：`pnpm dev` 看到左右分栏布局，左侧空白，右侧显示当前路由内容。

## 步骤 3：实现 `Sidebar.vue`

**做什么**：左侧导航栏，3 个导航项，用 `router-link` 切换页面。

**设计规格**（参考 BBPlayer 的底部 tab）：

| 属性 | 值 |
|---|---|
| 宽度 | 220px |
| 背景色 | `--md-surface-container` |
| 右边框 | `--md-outline-variant` |
| 导航项高度 | 48px |
| 激活色 | `--md-primary` 文字 + `--md-primary-container` 背景 |
| 非激活色 | `--md-on-surface-variant` 文字 |

**导航项结构**：

```
🏠 首页
📚 音乐库
⚙️ 设置
```

每个导航项包含：
- 一个图标（先用 emoji 占位，后续换 Material Symbols）
- 文字标签
- 选中态：文字变 `primary` 色，背景变 `primary-container` 色

**涉及知识点**：
- `<router-link>` 的 `to` prop 和 `custom` slot 用法
- `useRoute()` 判断当前路径是否激活，动态添加 class
- 在 `router-link` 上应用 Tailwind class 做激活样式
- `defineProps` 接收外部数据（未来可扩展）

**需要新建的文件**：
- `src/components/layout/Sidebar.vue`

**修改的文件**：
- `src/App.vue`（引入 Sidebar）

**如何验证**：点击左侧导航项，右侧内容区跟着切换。

## 步骤 4：创建 4 个 View 页面（骨架）

**做什么**：每个页面先放基础占位内容，确保路由和布局跑通。

### 4.1 `HomeView.vue` — 首页

内容：
- 顶部：标题 "BBPlayer"（`headlineSmall` 风格）+ 搜索栏（`input` 框，MD3 风格圆角 9999px）
- 中间：快捷操作卡片 2×2 网格（"每日推荐" / "最近常听" / "稍后再看" / "历史记录"）
- 所有卡片用静态假数据，`border-radius: 12px`，背景 `--md-surface-container`

**涉及知识点**：
- CSS Grid (`grid grid-cols-2 gap-4`)
- 卡片组件（可以内联在 View 里，也可以抽取到单独的 `components/home/QuickActionCard.vue`）

### 4.2 `LibraryView.vue` — 音乐库

内容：
- 顶部标题 "音乐库"
- 3 个子 tab（本地收藏 / B站收藏 / 稍后再看）
- 每个子 tab 显示一个空状态提示文字，或一条假播放列表项

**涉及知识点**：
- 子 tab 切换（用本地 `ref` 控制，不需要子路由）
- 条件渲染 `v-if` / `v-show`
- 列表渲染 `v-for`

### 4.3 `SettingsView.vue` — 设置

内容：
- 顶部标题 "设置"
- 分组列表项（用边框分隔）：
  - **外观** — 暗色模式 / 播放器背景 / 底部播放条样式（静态开关）
  - **播放** — 默认音量 / 播放品质（静态文本）
  - **关于** — 版本信息 / 开源许可

**涉及知识点**：
- 列表渲染 `v-for` 嵌套对象
- 分组布局（border-t / border-b 分隔）
- checkbox / toggle 样式（纯 CSS 实现）

### 4.4 `PlayerView.vue` — 全屏播放器

路由：`/player`
内容：
- 左半区：大封面图（squircle 圆角，用 `border-radius: 24px` 近似）
- 右半区：歌名 + 歌手 + 播放进度条 + 控制按钮组（上一曲/播放暂停/下一曲 + 随机/循环）
- 进度条：纯 CSS，一个 `<input type="range">` 或自定义 div

**涉及知识点**：
- flex 布局（左右分栏）
- 封面用 `v-bind:src` 绑定假图片 URL 或纯色占位
- `<input type="range">` 样式定制（`accent-color`）
- 图标按钮组（flex row + gap）

**需要新建的文件**：
- `src/views/HomeView.vue`
- `src/views/LibraryView.vue`
- `src/views/SettingsView.vue`
- `src/views/PlayerView.vue`

**修改的文件**：
- `src/router/index.ts`（已有，需确认 import 路径正确）

## 步骤 5：实现 `NowPlayingBar.vue`

**做什么**：固定在桌面窗口底部的一条浮动播放栏，显示当前曲目信息。

**设计规格**（参考 BBPlayer）：

| 属性 | 值 |
|---|---|
| 定位 | `fixed` 底部居中 |
| 宽度 | auto（由内容撑开）或固定宽 |
| 高度 | 56px |
| 圆角 | `border-radius: 24px` |
| 背景 | `--md-surface-container-high` 或半透明 + 毛玻璃 |
| 阴影 | `box-shadow` 大阴影 |
| 距底部 | `16px` |

**内容**：
- 左侧：小封面图（48×48，圆角 8px）
- 中间：歌名（`title-small` 粗体）+ 歌手名（`body-small`）
- 右侧：播放/暂停按钮 + 下一曲按钮

**交互**（后续再做）：
- 点击播放/暂停切状态
- 点击整个 bar 跳转到 `/player`

**涉及知识点**：
- `position: fixed` 的 z-index 层级
- `transform: translateX(-50%)` 配合 `left: 50%` 实现居中
- 条件渲染：没有当前曲目时整条 bar 隐藏
- props：从父组件或 Pinia store 获取曲目信息
- Pinia store 的 `storeToRefs` 提取响应式数据

**需要新建的文件**：
- `src/components/layout/NowPlayingBar.vue`

**修改的文件**：
- `src/App.vue`（在根布局中引入，位于 Sidebar 和 RouterView 的外层）

## 步骤 6：创建 `stores/player.ts`（Pinia）

**做什么**：管理播放器全局状态，供 NowPlayingBar 和 PlayerView 共享。

**初始状态（先写死假数据）**：

```ts
interface Track {
  id: string
  title: string
  artist: string
  coverUrl: string
  duration: number  // 秒
}

interface PlayerState {
  currentTrack: Track | null
  isPlaying: boolean
  currentTime: number
  queue: Track[]
}
```

**初始 actions**：
- `play(track: Track)` — 设置当前曲目并播放
- `pause()` — 暂停
- `resume()` — 恢复
- `next()` / `prev()` — 切歌

**涉及知识点**：
- Pinia 的 `defineStore`（option store 或 setup store 都行）
- `ref()` vs `reactive()` 的选择
- `storeToRefs()` 在组件中解构保持响应式
- 在 `main.ts` 中 `app.use(createPinia())`

**需要新建的文件**：
- `src/stores/player.ts`

**修改的文件**：
- `src/main.ts`（`app.use(createPinia())`）
